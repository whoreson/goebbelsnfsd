NFS Daemon Progress Notes
=========================

Current State (after M2 partial completion):
- M1: RPC over UDP/TCP, XDR codec, portmapper registration - WORKING
- MOUNT v1/v3: MNT, DUMP, EXPORT - WORKING (showmount works)
- NFSv2: GETATTR, STATFS, LOOKUP, READ, READLINK, READDIR - PARTIALLY WORKING

Issues:
1. FreeBSD kernel NFSv2 client fails to mount with "Operation not permitted"
2. READDIR reply format needs fixing (more flag, entry format)
3. File handle wire format: 32 bytes = magic(2 BE) + fid_len(2 BE) + fsid(8 BE) + fid(20 raw)
4. NFSv2 fattr is 68 bytes (not 32): type+mode+nlink+uid+gid+size+blocksize+rdev+blocks+fsid+fileid+atime+mtime+ctime
5. NFSv2 READDIR entry: cookie(4) + fh_handle(32) + name_len(4) + name(padded) + more(4)

Key fixes applied:
- nfs2_enc_fattr: now writes full 68-byte fattr with times and fsid/fileid
- File handle: opaque[32] with big-endian encoding
- MOUNT v1: fixed-size fhandle[32] (not var-length)
- NFSv2: fixed-size fh_handle[32] in enc_fh/dec_fh
- nfs_mode_to_type: converts UNIX mode to NFSv2 type

Still needed:
- Fix READDIR more/eof logic
- Implement NFSv3 (FSINFO, FSSTAT, PATHCONF) for full client compatibility
- Implement cred.c for proper ID mapping
- Test with remote client (10.0.0.198)

Test setup:
- Server: 10.0.0.186 (localhost)
- Client: 10.0.0.198
- Export: /tmp/nfstest or /tmp
- Mount: mount_nfs -2 -o udp,port=2049 10.0.0.186:/tmp/nfstest /mnt/test_nfs

Important: Use 'exec' in SSH to avoid sh treating 2>&1 as argument
